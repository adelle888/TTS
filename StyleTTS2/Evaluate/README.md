Evaluate
This directory contains validation and inference utilities for the StyleTTS2 reproduction.
Contents
- validate.py: validates checkpoints generated by the training pipeline.
- Inference_LJSpeech.ipynb: original LJSpeech inference workflow.
- Inference_LibriTTS.ipynb: original LibriTTS inference workflow.
Checkpoint Validation
A checkpoint generated by the smoke training experiment can be validated using:
python -m Evaluate.validate \
    --checkpoint Models/LJSpeech_smoke/first_stage.pth

The validation checks:
- checkpoint existence
- checkpoint loading
- checkpoint structure
- training epoch
- training iteration count
The reproduction checkpoint was successfully loaded and contained:
net
optimizer
iters
val_loss
epoch

The smoke experiment completed 10 training iterations and saved the checkpoint at epoch 0.
Inference Notebooks
The original StyleTTS2 inference notebooks are retained for reference.
Full speech synthesis requires the corresponding trained or pretrained StyleTTS2 checkpoints and, for some demonstrations, reference audio files.
These large external model files are not included in the reproduction repository.
